# 隐私政策

最后更新：2026 年 9 月 16 日

## 一句话版本

**战狗小助手不收集你的任何信息。**

没有服务器、没有账号、没有统计、没有广告。你在这个 App 里做的一切都留在你自己手机上。

## 我们收集什么

什么都不收集。具体来说：

- 不收集姓名、邮箱、手机号或任何身份信息
- 不收集设备标识符、广告 ID
- 不收集位置
- 不收集使用行为、点击记录、崩溃日志
- 不读取通讯录、照片、文件
- 不含任何第三方 SDK、分析组件或广告组件

## 你的数据存在哪

你输入的炮位坐标、记住的坐标、射击记录，全部保存在**你手机本地的应用沙盒里**。
这些数据不会离开你的设备。卸载 App 时它们会被一起删除。

## 网络

这个 App 在正常使用中**完全不联网**。飞行模式下所有功能一模一样。

唯一的网络请求发生在你主动点击「更多 → 检查更新」时：向 GitHub 读取本项目
最新发布的版本号，用来判断有没有新版本。这个请求**不携带任何你的信息**，
GitHub 会像对待任何一次普通网页访问一样记录该请求的 IP 地址，
这属于 GitHub 的服务器日志，我们看不到也不保存。

如果你从不点「检查更新」，这个 App 一次网络请求都不会发起。

安卓版本只申请一个系统权限 `INTERNET`，就是给上述更新检查用的。

## 儿童

本 App 不面向儿童设计，也不收集任何人的信息，包括儿童的。

## 变更

如果以后有任何变化，会在这个文件里更新，并写进版本更新说明。

# Privacy Policy

Last updated: 16 September 2026

## Short version

**This app collects nothing.** No server, no account, no analytics, no ads.
Everything you do stays on your own device.

## What we collect

Nothing. Specifically: no names, emails, phone numbers, device identifiers,
advertising IDs, location, usage behaviour, tap logs or crash reports.
We do not read your contacts, photos or files. The app contains no third-party
SDKs, analytics or advertising components.

## Where your data lives

The gun positions, saved coordinates and shot records you enter are stored in
your device's local app sandbox. They never leave your device and are removed
when you uninstall the app.

## Network

The app does not use the network during normal operation. Everything works
identically in airplane mode.

The only network request happens when you tap "check for updates" yourself:
the app reads the latest published version number from this project's GitHub
releases. That request carries none of your information. GitHub logs the
request IP as it would for any ordinary web request; that is GitHub's server
log, which we neither see nor store.

If you never tap "check for updates", the app makes no network requests at all.

The Android build requests a single system permission, `INTERNET`, solely for
that update check.

## Children

This app is not directed at children and collects no information from anyone,
children included.
